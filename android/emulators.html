Emulators

Emulators make it cheap to cover many screen sizes and OS versions.

Start an emulator

emulator -list-avds
emulator -avd Pixel_8_API_34 -no-snapshot-load

Simulate poor networks

emulator -avd Pixel_8_API_34 -netspeed edge -netdelay none
TipStart from a clean state with -no-snapshot-load when reproducing first-launch bugs.
